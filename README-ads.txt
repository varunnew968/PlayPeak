PlayPeak Adsterra Update

Files: index.html, script.js, style.css and branding assets.

Ad units integrated:
- Desktop banner 728x90: homepage top slot (shown for viewport widths > 780px).
- Mobile banner 320x50: homepage top slot (shown for viewport widths <= 780px).
- Native banner: catalog-bottom slot.
- 300x250 banner: game-player ad slot below the game controls.

The old head-loaded Adsterra banner, Social Bar and profitableratecpm script were removed to prevent duplicate/conflicting ad placements. The Google AdSense account meta tag was retained; it is not an ad script.

Copy/merge these files into your website root. If you already have assets/game-banners, keep that folder; this package only includes assets/playpeak-logo.svg.

Note: third-party ad scripts are loaded from the provider domain supplied by the site owner. If a placement remains blank, check that the ad unit is active/approved in the publisher dashboard and inspect browser console/network errors.
